# Agent project context

This `.agent/` directory is a **project convention**, not an automatically recognized standard in every IDE.

- `PROJECT.md`: goal, users, and acceptance criteria.
- `ARCHITECTURE.md`: verified boundaries; do not invent details.
- `context/`: confirmed constraints, stack, and glossary.
- `state/`: resumable context with evidence.
- `tasks/`: scoped work, backlog, and completed work.
- `plans/`: plans for nontrivial changes.
- `decisions/`: proposed and accepted architecture decisions.
- `quality/`: quality gate and verification strategy.

Review and fill explicit TODO fields before relying on this context. Commit these files if useful to your team. Maintain facts manually or with deliberate agent documentation updates.
